# Contributing

Thanks for wanting to help!

## Steps

1. Fork the repo
2. Create a branch: `git checkout -b my-feature`
3. Make changes
4. Run `pnpm lint && pnpm format:check`
5. Commit with [Conventional Commits](https://www.conventionalcommits.org/) (e.g. `feat: add cool thing`)
6. Open a Pull Request

## PR Rules

- Keep it small, one feature per PR
- Make sure CI passes
- Link related issues

## Questions?

Just open an issue
